# 旅行足迹 · Travel Footprints

**[打开交互地图 →](https://nacr05.github.io/travel-footprints-site/)**

一张慢慢填满的世界地图，记录走过的 **38 座城市、8 个国家**。

[![旅行足迹地图](https://nacr05.github.io/travel-footprints-site/assets/travel-map.svg)](https://nacr05.github.io/travel-footprints-site/)

网页采用深色底图与细小的蓝色光点，支持拖动、缩放、悬浮查看城市与到访月份、城市详情，以及可收起的城市列表。无需登录。

## 发布内容

这是网站的公开发布仓库。`website.zip` 包含网页运行文件、地图轮廓和已确认公开的城市记录；完整源项目与清单核对资料在独立的私有仓库维护。

更新 `main` 分支中的 `website.zip` 后，GitHub Actions 会解压并发布到 GitHub Pages。固定网址保持不变。工作流也可以从 Actions 手动运行。

## 来源

地图轮廓来自 Natural Earth，城市坐标来自 GeoNames，交互地图采用 MapLibre GL JS。随网页保存的第三方库、许可证和来源说明见 [THIRD_PARTY.md](https://nacr05.github.io/travel-footprints-site/THIRD_PARTY.md)。

公开可访问不代表授予整体开源许可证；第三方组件遵循各自许可证。
