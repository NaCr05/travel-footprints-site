# 愿望清单：第一版交互提案

日期：2026-10-11。状态：本地实现与验证、生产服务升级已完成，网页随本次 PR 合入后发布。本文保留方案背景，当前实现与操作见[愿望清单指南](wishlist.md)。城市搜索的官方来源、实测和限制见 [搜索研究](wishlist-search-research.md)。

## 已确认的边界

- 城市和可选的想去理由都公开，只有地图主人可以编辑。
- 沿用深灰地图、小尺寸标记、可收起侧栏，以及英文默认 / 中文切换。
- 推荐目的地与真实愿望清单分别保存；示意中的东京、巴黎等不代表用户真实愿望，也没有写入真实清单。
- 新功能复用已有 GitHub 登录和 Cloudflare 服务，不需要新增一套用户系统。愿望清单接口已实现，需要随服务入口一起部署。
- 用户选择香槟色空心圆，包含边框的外径与已有圆点保持一致为 6px；主地图提供独立显示开关并记住选择，侧栏收起仍可操作。

## 建议的体验

导航在 Albums 后增加 Wishlist / 愿望清单。打开后以原有侧栏显示已保存城市、国家和理由（有理由时才显示）；地图仍可拖动、缩放，侧栏仍可收起。

选择“添加城市”进入侧栏内的城市选择界面：搜索框在最上方，其下为人工精选目的地，以及中国 / 境外等轻量分类。输入后替换为结果列表，每条显示中英文城市名、国家和行政区，标识“已加入”“已去过”。选定城市后才出现可选理由和保存按钮，不要求填写未来旅行月份。

首版支持新增、编辑理由、移除。默认按加入时间倒序；不引入复杂优先级、行程规划和 AI 推荐。已去过的城市可以表达“想再去”，但用同一个地理 ID 关联，避免地图重复叠放两个按钮。

保存过程中清晰显示“正在保存”；服务确认写入成功后，当前清单与地图立即更新，其他访客在后台网站发布完成后看到更新。失败保留输入供重试。多标签页或照片保存导致版本变化时先刷新版本并核对冲突，不能覆盖其他人的或另一个页面的新内容。

## 城市搜索与推荐

建议从 GeoNames cities5000 构建可随项目分发的城市目录，仅在第一次打开城市搜索时加载，必要时分区域。名称搜索覆盖英语、已有中文名、常见简繁别名，以及经核对的常用拼音。不能承诺每个小镇或每一种拼音都被目录覆盖；找不到的地点应允许后续补充核对。

排序优先精确名称 / 别名，其次前缀和受限容错。人口只用于同名结果辅助排序，不能用作旅游热度。每次显示 8–12 个精选目的地，完整推荐集合可约 40–60 座，数量是待实现的产品建议。没有真实热榜来源时使用“精选目的地 / Destination ideas”，不标“实时热门”。

城市目录、推荐列表、用户愿望清单是三种独立数据。用户理由只送到自己的保存服务，不发送给城市搜索供应商。

## 地图标记选项（已选定空心圆）

| 样式 | 视觉意图 | 取舍 |
| --- | --- | --- |
| 香槟色空心圆（已选） | 6px 外径，已去过仍为蓝色实心点，想去用空心圈 | 与现有小光点一致，也通过形状区分状态。 |
| 淡紫色四角小星点 | 约 8–9px，像地图上尚未实现的星光 | 更有愿望感；很密集时辨认形状略难。 |
| 低饱和珊瑚色小旗 | 约 10–12px，语义直观 | 占据更多空间；全球尺度容易压过原来的点，适合少量愿望或放大后显示。 |

标记保持视觉尺寸小、可点区域较大。全局不常驻城市文字、不闪烁，也不以聚合计数大圆取代城市点。悬浮 / 键盘聚焦显示城市、国家、想去状态；点击进入理由详情。手机用点按。本次只增加愿望城市显示开关，已有足迹始终按原筛选条件显示。

已有到访记录又想再去的城市，以蓝色实心点叠加愿望外环作为建议复合状态；正式实施时再根据最终选定的标记统一设计。愿望城市不计入已去过城市 / 国家统计，也不混入到访时间线。

## 开发接入点

- `site/app.js` 的路由、导航、侧栏和 `renderMarkers`；新增愿望清单模块，避免继续扩大主文件职责。
- `site/styles.css` 的标记与侧栏样式；保持现有小点尺寸与地图投影。
- `site/i18n.js` 的文案与双语城市名称。
- 新的 `data/wishlist.json` 存选定城市 ID、原始 WGS84 坐标、国家地区、中英文名、可选理由、加入时间和来源。不要将显示投影坐标写回源数据。
- `upload-service/worker.js` 增加受现有 owner 检查保护的愿望清单读写接口；在固定数据路径内写入，校验长度、坐标和 ID，避免通用任意文件写接口。
- 发布工具包含愿望数据，后端返回确认版本，前端沿用照片功能的成功保存后即时更新与后台发布反馈原则。

## 验收重点

先测中文 / 英文 / 常用拼音与同名消歧，再测可选理由空值、重复加入、修改与移除、保存冲突、未登录禁止写入、保存失败保留草稿。地图验证小标记、悬浮和手机点按、已到访重叠状态、图层开关、统计隔离；检查窄屏新增导航不溢出。以实际构建产物测加载体积和手机输入反馈，再决定是否拆分目录。

本地开发分支已实现上述功能；正式愿望清单保持为空，测试城市未写入真实数据。生产上线状态以本次发布结果为准。
