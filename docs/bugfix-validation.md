# 审查后的缺陷修复

本轮修复现有流程，不引入数据库、本地编辑系统或新的登录方式。

- 照片同步：接受包含已保存提交的后续发布，正确展示其他页面的删除或说明修改；未发布的后续本机编辑仍保留，图片尚未可读时仍保留预览。
- 小型清单：空清单、未记录月份和只有一座城市的构建与相册校验可通过；空地图也能切换导航和语言。SVG 的月份空状态、局部地图数量根据数据生成。
- 城市身份：以唯一城市 ID 校验记录，允许同一国家存在同名城市。愿望清单的已到访标识按当前地图的城市名称、国家和坐标匹配，不直接信任目录中的历史标记。
- 大相册：GitHub Contents 不提供 base64 时，通过同一提交的 raw JSON 读取；照片和愿望目录共用该读取逻辑。权限、目标仓库和提交方式不变。
- 本地预览：仅服务已声明的网页资产、公开投影及被引用的媒体；拒绝外部 Host/Origin、跨站请求和符号链接／junction 文件路径。
- 导出：仅复制被记录引用的照片和故事文件，对城市、月份、照片及愿望记录逐层选择公开字段，避免把附加字段或闲置文件打包。照片原始文件不在这次修复中重编码；旧 CMS 图片的元数据策略仍见 `photo-cms.md`。

## 验证

`npm run check` 包含 68 项自动测试，以及构建、SVG、应用模型和相册校验。新增测试使用临时合成资料：空白／单城市、同名不同城市、大于 1 MiB 的合法相册、后续编辑覆盖、私人文件与附加字段、路径链接和外部来源请求。

浏览器另行核对空地图的导航、语言切换及搜索，以及现有相册按城市／月份分组。用户旅行记录与图片不作为测试修改对象。Cloudflare 的运行代码需要独立部署；源代码提交和 GitHub Pages 发布本身不能证明上传服务已更新。
